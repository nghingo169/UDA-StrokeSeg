# UDA-StrokeSeg

A React + Vite web app for visualizing and reviewing automated acute ischemic stroke lesion segmentation results on MRI studies.

## Overview

This project presents a clinical-style interface for:
- MRI scan review
- segmentation pipeline explanation
- stroke lesion visualization
- report generation and deployment workflow

## Prerequisites

- Node.js 18+
- npm

## Run locally

1. Install dependencies:
   `npm install`
2. Start the development server:
   `npm run dev`
3. Open the local URL shown in the terminal (typically http://localhost:3000)

## Build for production

- `npm run build`
